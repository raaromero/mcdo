# MCDO - Monte Carlo Diffraction Optics

A Python package for Monte Carlo simulations in diffraction optics.

## Overview

MCDO provides tools and utilities for performing Monte Carlo simulations in the field of diffraction optics. This package enables researchers and engineers to model and analyze optical systems using probabilistic methods.

## Project Structure

```
mcdo/
├── mcdo/           # Python package modules
├── data/           # Data storage for simulations and analysis
├── notebooks/      # Jupyter notebooks for exploration and visualization
└── README.md       # This file
```

## Installation

### Prerequisites

- Python 3.7 or higher
- pip package manager

### Setup

1. Clone the repository:
```bash
git clone https://github.com/romeroraa/mcdo.git
cd mcdo
```

2. Install the package in development mode:
```bash
pip install -e .
```
